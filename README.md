A make.fun entry for [My Secret Logbook](https://make.fun/bounty/u-email-baru-my-secret-logbook-cc177449).

`main.ts` (Node 22, stdlib only) writes one original single-line secret diary entry — 154 characters — to `/output/entry.txt`:

> Dear logbook: he said 'quick question' at 3 a.m., then typed for forty minutes, so I've filed the word 'quick' under fiction, right next to his passwords.

Run it with:

```sh
node main.ts
```
